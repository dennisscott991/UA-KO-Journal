UNITY ARENA KO JOURNAL – GITHUB PAGES

1. Gå til https://github.com/new og opprett et nytt repository, f.eks. unity-arena-ko-journal.
2. Velg Public (gratis GitHub Pages på standard GitHub Free). Ikke legg sensitive journaldata inn i GitHub-repositoriet.
3. Velg Add file > Upload files og last opp index.html, manifest.webmanifest og icon.svg fra denne pakken. Trykk Commit changes.
4. Åpne Settings > Pages. Under Build and deployment velger du Deploy from a branch, branch main, mappe /(root), og Save.
5. Vent på publisering. Nettsiden vil typisk ligge på https://BRUKERNAVN.github.io/unity-arena-ko-journal/ .
6. Åpne denne nettadressen i Safari på iPad. Velg Del > Legg til på Hjem-skjermen om ønskelig.

VIKTIG SIKKERHET OG LAGRING
GitHub Pages er offentlig og egner seg ikke som sikret løsning for sensitive operasjonelle personopplysninger. Journalene i denne utgaven lagres KUN i nettleserens localStorage på EN enhet, ikke i GitHub, og synkroniseres ikke mellom nettbrett, PC eller brukere. Bruk Sikkerhetskopi (JSON) og oppbevar den forsvarlig. Sletting av nettleserdata kan fjerne journalene. For faktisk drift med personopplysninger må løsningen vurderes med tilgangsstyring, sentral sikker lagring og personvernrutiner.
